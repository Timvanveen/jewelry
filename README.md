# Elowen Atelier — Jewelry Website Starter

An original, responsive jewelry storefront inspired by romantic, nature-led luxury design. Built with plain HTML, CSS, and JavaScript.

## Publish using GitHub Pages

1. Create a new public GitHub repository (e.g. `jewelry-website`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Visit the Pages URL GitHub provides (it may take a few minutes).

## Customize

- Change `Elowen Atelier` in `index.html` to your brand name.
- Change colors and typography in `styles.css`.
- Edit the `products` array in `script.js` to change names, prices, and photos.
- Replace all Unsplash demo image URLs with photos you own or are licensed to use.
- Replace `hello@yourbrand.com` and all placeholder brand story text.
- Prices are sample **AUD** prices, not real inventory.

## Important before launch

This is a front-end demo. The cart is interactive but **does not accept payments or create orders**. The newsletter form does **not** save email addresses. Connect a real checkout provider (such as Shopify Buy Button or Stripe hosted checkout) and a mailing-list service before selling. Add shipping, returns, privacy, terms, and contact policies. Verify photo licensing and accessibility before launch.
